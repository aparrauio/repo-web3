# Semana 03 · Clase 01 — TypeScript para estructuras reales de aplicación

Contenido práctico de la sesión, usando **`data/mortal_kombat_personajes.json`** como dataset
guía para el **Proyecto 1: Laboratorio de Intenciones Tipadas**.

## Qué contiene esta carpeta

La sesión práctica tiene **dos partes**, en el mismo orden que las diapositivas:

1. **`00-revision-proyecto-1/`** — revisión rápida (15-20 min) de lo que se espera como
   entregable del Proyecto 1, usando el dataset de personajes de Mortal Kombat: versión
   JavaScript avanzada → migración a TypeScript. Incluye checklist de requerimientos y un
   ajuste que debes completar para cumplir el mínimo de tipos personalizados exigido.

2. **`01-estructuras-reales-typescript/`** — el ejercicio principal. Usa el **mismo dataset**
   para practicar genéricos, tipos utilitarios (`Partial`, `Pick`, `Omit`), tipos literales,
   uniones discriminadas, enums, objetos anidados y funciones tipadas.
